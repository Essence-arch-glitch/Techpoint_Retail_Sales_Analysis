# TechPoint Retail Sales Analysis

## Project Overview
An end-to-end retail sales analysis project using Excel, SQL, and Power BI to evaluate business performance and uncover actionable insights.

The project examines sales trends, product performance, regional revenue, customer behaviour, payment methods, and order fulfilment.

## Business Objectives
- Evaluate overall sales performance.
- Identify top-performing products and categories.
- Compare revenue across regions.
- Analyse monthly sales trends.
- Understand customer segment performance.
- Examine payment methods and sales channels.
- Evaluate delivery performance.

## Tools Used
- Microsoft Excel – Data cleaning and preparation.
- MySQL – Data querying and analysis.
- Power BI – Data modelling, DAX and dashboard development.

## Key Findings
- Total delivered revenue: ₦224.97 million.
- Delivered orders: 536.
- Delivery rate: 86.45%.
- Units sold: 971.
- Retail customers generated the highest revenue among customer segments.
- North recorded the highest regional revenue.
- Laptops were the highest-revenue product.
- March revenue recovered after a decline in February.

## Project Structure
- Excel
- SQL analysis script
- Power BI dashboard screenshots
- Project documentation

## Dashboard
Three dashboard pages cover:
1. Sales Overview
2. Product Performance
3. Customer and Payment Analysis

## Conclusion
The analysis highlights revenue concentration across products and regions, changes in monthly performance, and opportunities to improve order fulfilment and business decision-making.
